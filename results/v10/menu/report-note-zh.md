# E1 菜单隔离：由已保存回执派生的报告草稿

本草稿仅读取 summary、ties、manifest 和两个阶段的 completion 回执。没有重新生成路径、校准、预测、选择惩罚或计算逐点评分。

正式计划为每来源 32 个配对重复，来源数为 13；完整 unit 为 416/416。完整 unit 数不替代每个方法格的完整性判定。

每个重复沿用冻结的 100*(QR/F-1) 浮点算术；先取来源内完整重复的中位数，再对全部预定来源中位数等权取中位数和描述性 IQR。没有成功来源子集汇总。显示值作小数舍入，注册判定使用完整精度；临界值核对以 report-values.json 为准。

M1：支持。constant 的 QR33、W=52 跨来源中位数为 0.21%；闭区间为 [-5.00, 5.00]%。
M2：不支持。switching 减 constant 的中位数差为 -0.43 个百分点；注册门槛为至少 5.00 个百分点。
M3：支持。两臂均严格改善的来源交集为 13，注册要求至少 12；未知来源为 无。来源条件不能用两臂改善来源的并集替代。

该比较更支持菜单是短历史表现的主要来源，未建立注册的 switching 增量；未过门槛不能写成总体等价。
