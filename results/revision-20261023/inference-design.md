# Post-result / exploratory inference protocol

Written after exact B5 recovery and before statistical test values. Original primaries and model selection are unchanged.

B1 uses paired left-minus-right stored pinball losses, Bartlett Newey–West covariance with denominator n and L=max(H,floor(4(n/100)^(2/9))). Report two-sided normal-reference DM p, HLN multiplier sqrt((n+1-2H+H(H-1)/n)/n), and Student t(n-1) HLN p; include 2L sensitivity. The HLN correction originates in MSPE comparisons; its extension to pinball is an approximation. Fixed finite training windows motivate the unconditional CPA interpretation under mixing, adequate high-order moments and a positive limiting long-run variance (Giacomini–White2006); these working assumptions are unverified. Shared estimation can create dependence beyond H; H alone is not a universal adequate bandwidth. Exact-zero loss variance yields NA, not epsilon regularization. Report24 conditional-versus-F cells and the two additional FX original/legacy contrasts; Treasury primary is among the24.

B3 uses original first-origin +j(H+1) sparse grid without annual resets. Hits are strict peak>capacity. POF tests exactly5% and can reject conservative rates when the target has atoms. Christoffersen independence uses transition counts and CC is explicitly full-n Kupiec POF plus transition-independence LR. A missing starting-state row yields NA for independence/CC. Boundary transition probabilities receive a warning. H+1 removes overlapping target paths, not shared-training dependence. Full-sample DQ-type HAC Wald uses instruments intercept, hits matured at lags H+1 through H+4, and issue-known capacity standardized on test instruments. It is an overlap-aware post-result adaptation, not the original iid one-step DQ. Drop unavailable earliest lags. Rank-deficient covariance yields NA with reason, not a pseudo-inverse reference chi-square.

B2 adjusts the fixed72 common-history conditional-versus-F/S/K contrasts by Holm using DM normal p; exact identical forecasts receive the conservative null p1 only for multiple-testing bookkeeping, with their test statistics NA. Primaries outside this family remain labeled separately.

B4 uses tau=.95 elementary quantile scores of Ehm etal2016 and evaluates all unique forecast/outcome breakpoints, retaining crossing/negative results. Exact finite-sample dominance is descriptive, not population dominance. Its integral must reproduce the paired pinball difference. Fixed tau with changing theta differs from the archived preference frontier, which varies preference weights on frozen reports.
