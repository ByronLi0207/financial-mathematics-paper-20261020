## Exact editorial suggestions, without changing any scientific claim

1. **CFTC title:** if the cited object remains the whole current index URL, replace the constructed reference title with *Historical compressed*. Keep the TFF subset identification in already existing methodological prose. This follows the owning page H1; it does not add a citation or a new data source.

2. **DOI/URL ending punctuation:** the current inline entries put a full stop after the `\url{...}` link. APA 7 explicitly omits the full stop after the DOI/URL. Remove only the terminal punctuation if the manuscript is being brought to strict APA 7; leave the identifiers unchanged. [Official APA DOI/URL guidance](https://apastyle.apa.org/style-grammar-guidelines/references/dois-urls).

3. **Corporate-author punctuation:** entries `fr2004_2013`, `fr2004_2024`, `cftcTFF` and `nyfeddata` currently join the spelled-out group author directly to the date. Strict APA separates the full corporate author with a period before the parenthesized date; e.g., `Commodity Futures Trading Commission. (n.d.).` This is punctuation only. [Official APA reference elements — group authors](https://apastyle.apa.org/style-grammar-guidelines/references/elements-list-entry).

4. **Retrieval-date placement:** for the two changing webpages/data tools, retain the recorded historical retrieval dates but place the wording before the URL as `Retrieved October 24, 2026, from ...` and `Retrieved October 23, 2026, from ...`, respectively, if strict APA is required. The date is original access provenance, not a new publication date or a date this review can retroactively establish. [Official APA reference elements — retrieval dates](https://apastyle.apa.org/style-grammar-guidelines/references/elements-list-entry).

5. **Gibbs proceedings completeness:** the existing author/year/volume/pages are correct. For a full edited-proceedings APA representation, the official BibTeX supports these additional source fields: editors M. Ranzato, A. Beygelzimer, Y. Dauphin, P. S. Liang and J. Wortman Vaughan; publisher Curran Associates, Inc. Use the target journal’s selected proceedings format consistently rather than mixing styles. The original PDF supports retaining `Candès, E. J.` despite the simplified metadata on the landing page. [Official NeurIPS BibTeX](https://proceedings.neurips.cc/paper_files/paper/11751-/bibtex), [Official APA conference-proceedings examples](https://apastyle.apa.org/style-grammar-guidelines/references/examples/conference-proceeding-references).

6. **Do not “correct” valid metadata into errors:** keep Diebold–Mariano 1995, CAViaR 2004 and Gneiting 2011 despite later platform posting dates; keep Boudoukh 2(3), 1–6 and MaxVaR; keep Christoffersen 841–862 despite the registry’s truncated start-page field; keep both specified Fed versions and their exact GUID URLs. These are preservation recommendations supported above, not proposed new claims.

The APA journal-article guidance supports including the assigned issue number and the DOI; the current audited journal entries already supply them. [Official APA journal-article reference examples](https://apastyle.apa.org/style-grammar-guidelines/references/examples/journal-article-references).
