## Analytic evidence R1: scale invariance

For a fixed model with positive parameter count p, write c=W/(H+1) and b=c/p. Sorting, grouping and raw-coordinate linear interpolation commute with this positive rescaling. Every resampled curve therefore has its root and interval endpoints divided by p. Consequently b<r_b/2 is equivalent to c<r_c/2, and b>2r_b is equivalent to c>2r_c. Mapping the b endpoints back to W multiplies them by (H+1)p, yielding exactly the c-based W band. The subsequent per-model screens cannot favor c over b. This statement does not replace the original pooled logistic selection: pooling models before fitting a common classifier is a different operation.

## Analytic evidence R4: horizon sorting

At a common issue origin let nested realized peaks satisfy y_short<=y_long and crossed reports satisfy a>b. With the same tau, replace (a,b) by (b,a). Since rho_tau(y-c)=tau(y-c)+(c-y)_+, the original equally weighted sum minus the sorted sum is

`(a-y_short)_+ - (b-y_short)_+ - (a-y_long)_+ + (b-y_long)_+`.

It equals the length of the intersection of [b,a] and [y_short,y_long], hence is nonnegative. Sorting uses available reports, not future outcomes. A shared observed floor remains satisfied after sorting. This provides no guarantee for each horizon separately, arbitrary horizon weights or scales, breach counts, or conditional coverage. The intended correction must state all these boundaries. The old artificial source already says its counterexample addresses raise-only repair, not every monotone rearrangement (`notes/revision-v5-novelty/theory-source.json`).
