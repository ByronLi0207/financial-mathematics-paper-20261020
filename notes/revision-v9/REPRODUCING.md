# Reproduction scope for the current v9 file package

There are separate levels of verification. The source ZIP supplies current TeX, figures and generated tables for document compilation without private financial data. Its isolated compile gate compares every page's extracted text and rendered pixels with the delivered documents. The public scalar JSON/CSV/tables and paired synthetic traces support the named saved-result and arithmetic checks. These facts alone do not establish independent financial replication.

The formal WP2 and WP3 designs were committed locally before their new runs, after the broader research history was already known. Native browser uploads create a different public Git history and do not export those original local objects. Existing sealed drivers and some history-dependent tests therefore remain BLOCKED in a fresh browser-published clone. Independently, the original WP2 formal driver enforces its expired research-window deadline. The saved-trace WP2 auditor also reads the original local design commit. Neither a complete synthetic archive nor access to one input removes these independent restrictions. Do not remove an ancestry or deadline guard, relabel a replay as formal, use a different design commit, publish a private identity bundle, or claim that an identical file tree repairs missing history. The current local full-suite receipt states its actual local source cut and environment; it is not a public-clone pass.

The complete public synthetic archive is `results/revision-v9/wp2/wp2-driver-output.tar.gz`, with its complete `wp2-driver-output-members.csv` index and package receipt. The financial scalar archive is `results/revision-v9/wp3/wp3-scalar-driver-output.tar.gz`, with its member index and full contrasts beside it. Acquisition fingerprints and clocks are in the frozen protocols. Raw FX observations and private per-issue vectors stay outside tracked files because free access is not redistribution permission. Obtain exact rights-cleared source bytes before financial replay, retain New York Fed attribution/source conditions, and never infer a new dealer or prospective sample from arithmetic agreement.

Compile current saved TeX with the existing Tectonic cache or an already available compatible TeX installation. No automatic installation, download, financial fit, new experiment or future-data issue is part of the document checker. Current results retain all failed/NA/counterexample statuses. Commands in `REVISION_V9_CHANGELOG.md` and the exact version-specific receipts are historical execution evidence, not a current fresh-clone recipe for rerunning the sealed formal drivers.

Their success reports display consistency only. The complete software suite's historical local environment includes original local Git objects; its archived result must not be generalized to a fresh public clone.
