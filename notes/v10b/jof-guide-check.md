- Free Format初投接受一致的参考文献格式；正式刊物采用APA。本稿author-year、参考文献字母排序，作者/年份/标题/刊名卷页与DOI字段一致；无本轮新文献。
- 关键词最多6个：本稿6个。
- running title要求少于40字符（严于用户“不超过40”）：Historical Rules and Peak Limits，32字符含空格。
- 原生LaTeX须附peer-review PDF和引用的支持文件；本轮重建完整依赖ZIP，补充材料单独PDF。
- data availability声明存在：FX权利/取得路线、NYFed条件、官方CFTC文件与fingerprints分别说明。
- code availability链接统一revision-v10b；公开结果和受限金融回放分别说明。

- 指南要求图下caption，并列完整legend清单；本稿图下caption全部保留，另附投稿文件figure-legends.tex，打包时同列。
- 本轮限制：main<=20pages、supp<=33、letter<=1page；这些是用户约束，未伪称期刊硬页限。
