## Defect and bounded correction

The first checker verified table lengths and numerical rows but did not require each expected semantic key exactly once. A duplicate otherwise valid comparator row could replace an omitted comparator while retaining the row count. Numerical correctness of a visited row does not establish the completeness of the declared comparison inventory. A root aggregate-only check found all 192 currently published row keys unique; that observation alone was not a sufficiently strict reusable checker.

The refined checker requires the exact source/H/W/year/comparator key sets and their method, unit, update, status, parameter, role and stride labels. It binds every consumed public/private export to the exact manifest inventory, parses CSVs from the same bytes whose size/hash it checked, and rejects duplicate retained refits before building a lookup. It checks all retained fit-record schedule/maturity/finite acceptance metadata and cell-receipt/source/selection/artifact identities. Relative-loss arithmetic divides before multiplying by100 and retains the declared reason when a relative value is undefined. The numerical tolerances and 24 selected Fraction/recursion checks are unchanged.

The 22 targeted synthetic tests include actual demonstrations of the earlier wrong-label and duplicate/omission gaps, corresponding rejection cases, exact export/snapshot checks, large-number relative-loss cases, represented high-offset OLS and no-after-refit scalar replay. A complete artificial eight-cell main-path fixture exercises the inventory, labels, CSV/NPZ binding, 24 exact OLS and 24 scalar reports and 192 aggregate rows; only its preverified-replication/source boundaries and output/resource plumbing are injected. It does not read the financial sources or generate a real financial forecast. The limited suite passed in 0.058 seconds; its separate process used 44,728,320 bytes peak RSS and0.13 seconds externally. One numerical thread was requested; that test measurement did not independently sample OS thread counts. A separate read-only execution also passed all22 cases. These are test results, not extra financial observations or research hours.
