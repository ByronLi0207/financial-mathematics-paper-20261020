The procedures share the response, issue convention and native evaluation preference, not identical finite-sample fitting objectives. When plain RichKNN chooses k=W, it uses the entire frozen pool and is exactly frozen F under the same rank/arithmetic. This boundary appears in W52/k52 and W720/k720 menus. If selected, it is a full-pool fallback, not evidence for a rich-distance feature effect. Scale-adjusted KNN at k=W still changes response normalization. Eligible-pool/update matching does not equalize effective local sample size, function form, regularization or validation selection; the contrasts compare complete procedures rather than identify an isolated causal information effect.

## Failure, phases and executable contract

The exact phase inventory is validation, selection-freeze, evaluation and historical-reference evaluation. Validation/evaluation are divided into the predeclared source/H/W/family cells (two sources, two horizons, two windows per source, three conditional families). Each validation cell evaluates its three fixed candidates in increasing numeric order. A numerical fit failure stops that candidate without producing a complete score, is recorded with its refit/diagnostics, and makes the whole family/source/H/W ineligible for selection; the remaining declared candidates may still be run to document numerical feasibility, but cannot become a replacement selected model. If any candidate lacks its complete common validation origins, that cell's selected parameter is null. Resource or source-integrity failure stops the current phase rather than classifying forecast accuracy. Continue other independent cells under the unchanged freeze and publish all terminal statuses.

Selection-freeze binds complete validation receipts, their hashes, exact lowest-native-unit-loss settings and the null cells before any evaluation phase. A selected evaluation method must issue on every common evaluation origin. Any failed refit stops the whole cell with no complete mean accuracy, no omitted rows, no alternate candidate and no fallback forecast. Preserve partial numeric traces privately and public scalar failure diagnostics. Historical-reference phases are source/H/W cells and retain rolling, frozen and one-state references even if a conditional cell fails. A technical replay must use identical code/spec/source hashes, retain every earlier attempt and state its reason; no wider grid, changed tolerance or alternative source is permitted after financial outcomes.

For a frozen fit pool, retain actual query t and distinct refit r; assert r<=t<r+step and pool exactly [r−H−W+1,...,r−H], with every label end<=r. The query feature, current anchor and floor always use t. Frozen S is recomputed from the historical pool's increment envelopes at N_t; it is not a frozen issued capacity. Do not pass r as t to bypass the existing rolling-window validator.

Single financial process; request one numerical thread and observe OSthread/RSS snapshots. Internal stops540seconds/1.5GiB, hard600secondalarm, public budgets600seconds/2GiB/twoobservedthreads. One run may be split in predeclared source/H/W phases to preserve bounded computation, never to hide retries or change specifications after losses. Raw download cap2MiB for the current external CSV, overall existing100MiB. No software installation/GPU/daemon or wide search.
