# v6 common before-execution contract

Status: freeze before any v6 financial benchmark. All new analyses are post-result / exploratory. The evaluation archive has already been inspected. This is not prospective preregistration, independent dealer validation, a new primary or a new guarantee.

The unmodified `protocol/revision-20261022/study-spec.json` owns both source hashes, record indices, H in {6,24}, W in {720,2880} for FX and {52,260} for Treasury, the original validation/evaluation split, refit cadence, transforms and numerical QR acceptance. No economic-date/public-release reconstruction is introduced. The current source/trace inventory is admission evidence, not a new scientific result. Verify source bytes, trace manifests, exact common origin vectors and all six original aggregate CSV bytes before consumption; a discrepancy stops the affected WP and is retained. Additional panel traces lack historical public NPZ hashes: verify their current fingerprints and reproduce original public summaries before combining; do not call the new fingerprints old public validation.

Every estimate at r uses exactly origins [r-H-W+1,...,r-H]; every response there ends no later than r. Queries and floors use actual t. Original validation/evaluation refit grids stay anchored at their respective original segment starts. Earlier evaluation labels can enter later fits only when mature. No unit pooling, interpolation, label shortening, favorable row removal, alternate source or changed primary is permitted. New private per-origin vectors stay in `.scratch/revision-v6`, public outputs are complete aggregate results and input/code fingerprints. Neither raw FX nor third-party article PDFs are published.

Use one numerical worker, request one numerical thread (observed maximum two), record wall time and peak RSS. Internal limits 540 seconds / 1.5 GiB, hard limits 600 seconds / 2 GiB per declared source/H/W/phase worker. A resource/solver/data failure stops that cell and records NA; no shorter evaluation or retrospective smaller menu. No system install, interpreter download, GPU, daemon or deletion. Existing runtimes and cached temporary `uv run --with` dependencies only. Old archives, old source code and both original primary values remain immutable; versions of new methods are separate files.

All new ranking tests are working-reference diagnostics. Use the original DM/HAC and HLN convention with L=max(H,floor(4(n/100)^(2/9))) capped at n-1; preserve its unverified dependence/moment/finite-sample limitations. Sparse hits use exactly first evaluation origin+j(H+1), without selecting a favorable offset. New v6 CC is explicitly transition-conditional: compare the saturated two-row Markov transition likelihood to the fixed-alpha transition likelihood on n-1 pairs, conditioning on the first hit. Show full-sample Kupiec separately. Missing transition rows, zero covariance, rank deficiency and other reference failures are explicit statuses, not proof of calibration. Old v3 CC values/definition remain untouched. Coverage p-values are unadjusted diagnostic outputs and do not certify conditional coverage or absence of floor atoms.

Separate frozen ranking families: WP2 56 slots; WP3 224 slots; WP4 4 slots; WP5 6 slots. Output every slot, component raw p (or NA), and Holm bookkeeping p (NA mapped to 1) separately; family counts cannot shrink after failure. These adjustments do not cover all historical model/analysis selection or validate invalid component reference distributions. No old 72-/48-slot family is relabeled. Reference directions are always new procedure minus named control, with source/H/W/update/tau/contrast ID retained.

All finance is deterministic; record seed20261023 as the reproducibility/test seed, not a claim that a random optimization or new stochastic simulation was used. No favorable-result retuning. Only the authorized WP2–WP5 analyses may be run. After WP7 the loop samples source-bound numbers, references and existing prose; it adds no analysis and changes no conclusion.
