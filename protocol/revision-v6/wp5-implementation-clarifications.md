# WP5 executable clarifications, before financial controls/new target levels

The scientific design remains `wp5-quantile-levels.md`; this file states implementation and admission details without changing any menu, split, clock or failure rule.

- `v6_tau.forecast_qr_tau` is a single generic-level implementation using the unchanged original features, training-only transforms, response normalization, solver defaults and original segment-anchored refit clock. No .95 bypass returns archived capacities. Full financial validation/evaluation QR arrays at .95 and the named full evaluation F controls must first equal the original admitted vectors exactly. These controls verify implementation on the actual original inputs; they are not new independent validation.
- Controls require the exact source/level, complete named check inventory, full segment counts, vector/source-trace hashes and the executable freeze. Every later receipt binds the same control hashes. Summary admission independently checks receipt headers, current freezes, full original evaluation origins, source-derived peaks/floors, finite reports respecting the floor, trace bytes/hash and recomputed score identities. A self-consistent shortened trace is not admissible.
- Every source/target-level validation uses all three original ridge penalties in original order, unless a predeclared information screen or resource limit prevents fitting. All attempted and unattempted candidates remain explicit. Any failed/incomplete candidate invalidates the whole QR cell. Exact loss ties use the larger penalty. All four validation receipts are bound into a selection freeze before any new-level evaluation.
- Two source controls and each source/level/phase run serially in separate processes, with one requested numerical thread. Resource exhaustion produces a whole-phase NA receipt and retains failed/unattempted menu entries. A failed .95 identity/control gate stops WP5 rather than admit new target-level outputs. Identity, programming and provenance errors are not relabeled as statistical model failure.
- The six fixed comparisons are tau .90 and .99 crossed with FX original primary (QR2880 minus rolling F720), FX matched (QR2880 minus frozen F2880) and Treasury original/matched single contrast (QR260 minus frozen F260). Each result names reference, update, horizon and windows. Descriptive mean differences and their .95 sign comparison remain available if an inferential working-reference calculation is NA; an NA p-value is never fabricated. Raw NA and Holm bookkeeping 1 remain separate.
- The original .95 financial engine and outputs are unchanged. All new target-level outputs are post-result / exploratory. Different levels define different pinball objectives; absolute losses across levels do not measure the same decision cost.
