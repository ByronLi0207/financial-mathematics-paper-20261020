# Working paper and source

**Historical Headrooms versus Current-State Scenarios for Sampled Inventory Peaks** is a 12-page English working paper: nine pages of text, tables, appendices, references and captions, followed by the three original aggregate vector figures. It reports the complete fixed design and its adverse results as well as the primary finite-record improvement.

- [paper.pdf](paper.pdf): reviewed standalone paper.
- [main.tex](main.tex): self-contained LaTeX text/tables/references, with the three relative figure paths.
- [paper-content.json](paper-content.json): common structured manuscript content and explicit equation representations.
- [rendering-verification.json](rendering-verification.json): actual source/PDF identities, compilation status and rendering checks.
- [figures/](figures/): the original scientific vector figures bound by the run manifest.

The current `main.tex` was successfully compiled by the desktop editor's built-in LaTeX compiler. That interface returned compilation diagnostics and did not expose a standalone export. The supplied `paper.pdf` is independently typeset from the same structured content using ReportLab, followed by the untouched vector figure pages via pypdf. It is **not claimed to be an export of the LaTeX compiler**. Pagination and text fonts can therefore differ when `main.tex` is compiled elsewhere; the scientific content and canonical figure files are shared.

From the repository root, use `python3 -B build_paper.py --output .scratch/paper-rebuilt.pdf` in the documented existing environment to rebuild the independent standalone PDF without replacing the delivered file. `requirements-paper.txt` records ReportLab4.4.9 and pypdf6.10.0. The builder uses the four existing macOS Times New Roman fonts under `/System/Library/Fonts/Supplemental/`, embeds document subsets, and fails clearly if required fonts are missing. Font files are not distributed. No source observations or scientific results are recalculated by this document builder.

The companion `python3 -B build_tex.py --output .scratch/main-rebuilt.tex` regenerates the TeX source from the same structured content without overwriting the delivered source. Its generated bytes were verified identical to the successfully compiled `main.tex`.

The scientific code, data access and interpretation are described in the [root README](../../README.md) and [results README](../../results/README.md). The source dataset and third-party papers are not included or relicensed.
